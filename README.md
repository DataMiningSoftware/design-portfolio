# Design Portfolio

A standalone static portfolio site for graphic-design work: the schematic transit map, the RoomieMatch UI, and society promo assets, plus a short case study.

## Run

Just open `index.html` in a browser — no build step. To publish it, drag the folder into Netlify Drop, or host `index.html` + `styles.css` on GitHub Pages.

## Customizing

- Replace each `.placeholder` block with your actual image (`<img src="...">`).
- Rewrite the case study to match one real project.
- Update the name/tagline in the hero.

## Files

- `index.html` — structure and copy.
- `styles.css` — a simple dark theme.

## Caveats

- The three project sections and the case study are currently placeholders — fill them with your real assets before sharing.
- This is a single-page static site (fine for a portfolio). Add more pages or a gallery if you have more work.
